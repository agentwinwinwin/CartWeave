# 商品图生成与推广投放

## 两条独立业务流程

1. 商品图生成：选择商品事实与参考图 → Skill 制定方案 → 图片服务 Skill 生成 → 系统一致性检查 → 人工确认 → 交付素材包。商品无需先上架，可以为选品结果或已有商品制作图片。
2. 推广与首次投放：定义推广任务 → 制作文案与创意（引用确认的商品图包） → 确认素材与花费 → 提交暂停广告 → 等待渠道审核 → 启动 → 记录结果。继续保留完整七步业务链；需要新商品图时另开素材任务，不在创意节点重复生图。

## 前后端边界

当前新增的是同一设计器中的前端模板、配置权限与契约草案，不是已完成的图片执行器或广告适配器。后端现有 CJ 到测试站的受信执行主线保持不变；新增模板不能真实冻结执行或安排定时器，不冒充已经生成素材、交付任务或启动广告。

后端接入时，引用必须解析成归属同一工作区的真实记录；校验商品/规格、素材来源、用途许可、版本及摘要。模型连接与图片服务凭证仍在服务端，不进入节点参数。图片检查不能保证视觉事实自动可信，需保留人工核验意见；素材包被修订后不得沿用旧批准。

投放应保存素材版本、投放范围及花费授权；商品图确认不能替代花费批准，广告账户不是店铺连接。提交保持幂等，结果未知先查询原操作，平台审核通过不代表获得花费授权。商品图包仅显式引用，不自动写入已上线商品或启用广告。

## 兼容

目录只新增商品图生成，`campaign` 保持推广与首次投放的七步流程。旧文档普通加载和保存不拆分、不重写参数、冻结快照、运行或定时器；新的商品图引用与创意配置需显式编辑应用。没有新增执行器注册或绕过审核。
