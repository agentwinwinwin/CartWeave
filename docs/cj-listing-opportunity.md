# CJ 订单与刊登关注度选品 v5

已实现入口 `apps.skills.opportunity_listings`，版本 `product.opportunity@5.0.0`。
沿用 `DeliveryCandidates@1 → SelectionProposal@1`，独立注册，不覆盖 v4。

## 确定性评分

| 指标 | 权重 | 计算 |
|---|---:|---|
| CJ 订单数 | 45% | 本商品订单数 / 本批可评分商品最高订单数 × 100 |
| 刊登关注度 | 25% | 刊登次数 / (刊登次数 + 100) × 100 |
| 到货成本 | 15% | 最低到货成本 / 本规格到货成本 × 100 |
| 时效 | 10% | 最短总时效 / 本规格总时效 × 100 |
| 库存 | 5% | min(可用量 / 50, 1) × 100 |

工厂供货仍扣10分，总分不低于0。并列按成本、时效、规格ID稳定排序。
刊登100次为50分、900次为90分，递增饱和以防极值占据排名。
这些权重是初始规则假设，未经经营回测，不承诺选品盈利。

## 数据和执行边界

- 使用既有详情接口 `orderCount` 与 `listed`，不新增网络请求。
- 刊登次数是关注度代理，不是销量、独立商家数、广告热度或目标市场竞争。
- 订单周期及国家未声明；订单未达门槛仍淘汰，刊登高不能代替订单。
- 刊登0可评分；未知刊登排除并保存原因，不能填0或擅自重分配权重。
- 最低订单数合格才占候选额度；候选额度不承诺刊登、库存或配送资料完整。
- 建议售价与税费核算不变，不因刊登高自动涨价。
- 保存各项分数、刊登原数与版本；审批和发布前用冻结算法重新校验摘要。
- 单元测试和合成批次发布回归使用模拟数据，不表示已在真实CJ执行或自动批准。

本地安装：`COMMERCE_ENV=local COMMERCE_DESKTOP=1 ../server/.venv/bin/python manage.py register_opportunity_skill --cj-listings`。
技能模块与任务节点从同一注册表选择新版本，旧冻结版本与历史审批不改。
